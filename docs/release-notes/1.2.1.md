## PFXtract 1.2.1

Cette version améliore l’interface et rend PFXtract entièrement bilingue.

### Nouveautés

- Interface disponible en français et en anglais, avec le français par défaut.
- Nouvelle icône PFXtract dans l’application, la barre des tâches et l’exécutable.
- Champs et boutons réalignés pour un affichage plus clair.
- Affichage normalisé des blocs PEM `CRT`, `KEY` et `CABUNDLE`.
- Bouton **Aide** et numéro de version accessibles depuis le bas de la fenêtre.
- Liens cliquables vers la page officielle de PFXtract depuis l’aide et le numéro de version.
- Commentaires ajoutés au code afin d’en faciliter la maintenance.

### Téléchargement

Téléchargez **PFXtract-win-x64.exe** dans la section **Assets** ci-dessous. Il s’agit d’un exécutable autonome pour Windows 64 bits; aucune installation séparée de .NET n’est requise.

Le fichier `PFXtract-win-x64.sha256` permet de vérifier l’intégrité de l’exécutable téléchargé.

### Sécurité

L’extraction est effectuée entièrement sur l’ordinateur. Le mode **Copier CRT / KEY / CA** affiche temporairement la clé privée non chiffrée afin qu’elle puisse être collée dans un formulaire SSL; cette clé ne doit jamais être partagée.
